# 结论及其成立条件（v0.1）

所有结论都针对 [model.md](model.md) 中的单期模型。数值来自示意性参数（见 `experiments/common.py`），用于展示机制，**不是对现实经济的预测**。

状态分为三类：
- **已证明**：在所述假设下有解析证明；
- **模拟观察**：在所报告的参数范围内由模拟得到；
- **待验证**：猜想。

复现方式：`uv run python -m experiments.run_all`，结果写入 `results/<实验>/`（summary.json 中记录配置、随机种子和 git commit）。

## F1. 只改变所有权和融资方式，不改变线性福利

| 项目 | 内容 |
|---|---|
| 问题 | 开源和闭源的差别是否可能只是分配差别？ |
| 假设 | $r,o,\tau,\kappa,h$ 及技术参数不变，只改变 $a,\omega,\beta,d,\delta$ |
| 结论 | 每个样本的 $S,C,R$ 都不变，因此线性福利 $W$ 完全相同；凹效用下的福利、各群体的收益和风险可以差别很大 |
| 证据 | 由 §7 的核算恒等式直接推出；`tests/test_core.py::test_pure_transfer...`；`results/distribution` 中同一 η 下 $W_{\text{linear}}=1.822$，四种制度相同 |
| 敏感性 | 一旦融资或所有权影响投资量或开放规则（v0.1 不包含），结论不再成立 |
| 状态 | 已证明 |

## F2. "公共出资、私人所有"在凹效用下表现最差

| 项目 | 内容 |
|---|---|
| 问题 | 在相同的 $S,C,R$ 下，哪种所有权与融资组合让最多的人受损？ |
| 假设 | 基线参数；所有权集中于投资者（人口 10%）或按人口分布；公共融资按收入比例征税；η=0 |
| 结论 | 集中所有加公共出资时，研发成本由全社会承担，厂商收入 $\tau S$ 归投资者：受损人口比例为 75.6%，对数福利为 0.345（四种组合中最低）。广泛所有加公共出资时，受损比例为 9.4%，对数福利为 0.495（最高） |
| 证据 | `results/distribution/table.md`，50,000 次抽样，四种组合使用同一组随机数 |
| 敏感性 | 加入收入转移（η=0.3）后，最好（广泛所有加公共出资）和最差（集中所有加公共出资）的位置不变，集中所有加公共出资的受损比例升至 87.2%；中间两种组合的顺序互换，广泛所有加私人融资升到第二 |
| 状态 | 模拟观察。排序依赖于 $\tau$、税负份额和 $a_g$ |

## F3. 广泛所有权加私人融资，会把投资风险转给劳动者

| 项目 | 内容 |
|---|---|
| 问题 | 所有权分散，风险是否也随之分散？ |
| 假设 | 同 F2，所有权和成本份额都按人口分布（$\beta=\omega$） |
| 结论 | 劳动者承担了 60% 的研发成本，但应用端收益较少：劳动者受损概率为 34.8%，而集中所有加私人融资时为 0%。所有权分散了收益，也让收入较低的群体暴露在研发失败风险之下 |
| 证据 | `results/distribution/table.md`，P(loss) workers 一列 |
| 敏感性 | 结果取决于 $a_g$ 与 $n_g$ 的比值；如果劳动者获得的应用端收益份额更高，该效应会减弱 |
| 状态 | 模拟观察 |

## F4. 固定预算下，只有"回报递减、高度不确定、低相关"同时成立时，分散研发才能提高预期前沿

| 项目 | 内容 |
|---|---|
| 问题 | 把预算 $R$ 平分给 $k$ 个对称项目，能否提高 $\mathbb E[\max_j q_j]$？ |
| 假设 | $q^0=0$；$f(r)=A r^\alpha$；$Z$ 为对数正态，均值 1、标准差 σ、相关系数 ρ |
| 结论 | (a) 若 $\sigma=0$，$k=1$ 最优；(b) 若 $\alpha\ge1$，对任意 σ、ρ 都是 $k=1$ 最优；(c) 若 $\alpha<1$，$k=2$ 优于 $k=1$ 当且仅当 $2\Phi\big(s\sqrt{(1-\rho_X)/2}\big)>2^{\alpha}$，其中 $s^2=\ln(1+\sigma^2)$ |
| 证明 | (a) $f$ 单调递增。(b) $\mathbb E\max_j Z_j\le\sum_j\mathbb E Z_j=k$，所以 $(R/k)^\alpha\,\mathbb E\max_j Z_j\le R^\alpha k^{1-\alpha}\le R^\alpha$。(c) 由对数正态最大值的期望公式得到 |
| 证据 | 在 α=0.5 时，模拟中只有两种情形出现显著收益：ρ=0、σ=1 时 k=2 提升 2.4%；ρ=0、σ=2 时 k=8 提升 34.6%。ρ=0.6 时，所有情形都没有显著收益（`results/rnd/table.md`，20 万次抽样，判定标准为超出 k=1 解析值 2 个标准误） |
| 敏感性 | 最低启动成本 $c=0.03$（预算的 10%）会把 σ=2 时的最优项目数从 8 降到 2，提升从 34.6% 降到 9.3%。若以闭源、κ=3 条件下的 $\mathbb E[S]$ 衡量，最优 k 更小（σ=2 时为 3），因为用户并不都用到前沿能力 |
| 状态 | (a)(b)(c) 已证明；具体数值为模拟观察 |

**含义**："技术进步很随机"本身不足以支持分散投入：还需要回报递减，以及各项目的研究路线不高度相关。

## F6. 单期模型中，开放的价值来自"让用户用上前沿能力"，市场越不集中于最好的模型，这一效果越大

| 项目 | 内容 |
|---|---|
| 问题 | 在投资、所有权和融资都不变时，只改变复用规则会带来什么？ |
| 假设 | 基线的 3 个非对称项目；厂商 0 由投资者所有，厂商 1、2 由投资者和"其他群体"各持一半；$\tau$ 外生 |
| 结论 | 全部开放时，所有厂商的可用能力都等于前沿，$S=s(\max_j q_j)$，与 κ 无关。相对于全部闭源，$\mathbb E[S]$ 的增量随 κ 增大而缩小：κ=0.5 时 +0.185，κ=20 时 +0.011。只开放领先项目，会降低领先厂商的预期利润，提高落后厂商的利润 |
| 意外现象 | κ 较大时，只开放落后项目反而提高了领先厂商的利润（κ=10 时 0.118，全部闭源时 0.096）：当某个落后项目碰巧超过领先者时，领先者可以复用它 |
| 证据 | `results/openness/table.md`，10 万次抽样，与全部闭源配对比较（标准误 ≤ 0.0005） |
| 敏感性 | (1) $\tau$ 外生，因此开放不会削弱厂商的定价能力，会高估开放后的厂商收入。**定价内生后，关于厂商利润的部分不再成立，见 F7。**(2) 开放非前沿项目在理论上可能降低 $S$（被提升的落后者从更强的闭源厂商那里夺走份额），基线中未出现。(3) 单期模型不包含知识积累，这是开放可能最重要的效应 |
| 状态 | 模拟观察 |

## F7. 定价份额随领先幅度变化时，开源把价值从厂商所有者转给用户（单期）

| 项目 | 内容 |
|---|---|
| 问题 | 如果开源会削弱厂商的定价能力，F6 的结论还成立吗？ |
| 假设 | F6 的设定（κ=3）；按领先幅度定价（model.md §12），$\tau_{\min}=0.1$，$\tau_{\max}=0.7$，$s=0.2$；对照组为固定 $\tau=0.5$ |
| 结论 | 单期内，定价方式不改变 $S$，只改变谁拿到它。按领先定价时，厂商分成随开放程度下降：全部闭源 0.42，只开放落后项目 0.32，只开放领先项目 0.16，全部开源 0.10（=$\tau_{\min}$，可证明）。投资者的平均资源从 4.55 降到 3.46，劳动者从 1.149 升到 1.319，其他人从 2.27 升到 2.59。而在固定 τ 下，全部开源反而让投资者从 4.69 升到 4.83 |
| 推翻的结论 | F6 中"只开放领先项目会提高落后厂商的利润"不再成立：按领先定价时，落后厂商的利润从 +0.014 / +0.044 变为 −0.044 / −0.027。全部开源时，三家厂商都亏损 |
| 证据 | `results/pricing/table.md` 第 A 部分，5 万次抽样，固定与按领先定价使用同一组随机数；`figure_one_period.png` |
| 敏感性 | 方向在 κ = 1、3、10 下都成立。κ=10 且全部闭源时，两种定价的厂商分成接近（0.49 对 0.50），因为市场本来就集中于领先者 |
| 状态 | 全部开源时 $\tau_j=\tau_{\min}$ 为已证明；其余为模拟观察 |

## F8. 多期中，定价内生后私人开源可能无法持续：存在 $\tau_{\min}$ 临界值

| 项目 | 内容 |
|---|---|
| 问题 | 开源压低定价能力后，私人出资的厂商还能撑下去吗？ |
| 假设 | 多期草稿模型（model.md §11）；每期预算 0.3 平分给存活厂商；初始资本 $K_0=0.3$；没有新厂商进入；厂商全部退出后，用户免费使用公开技术；η=0；2,000 次抽样，25 期 |
| 结论 | (a) **私人开源崩溃**：按领先定价时，97.5% 的历史中所有厂商在第 25 期前退出，大多发生在第 7–11 期。技术停在 3.75（固定定价时为 10.0），累计研发投入只有 2.6（应为 7.5）。(b) **私人闭源走向垄断**：落后厂商分成低、亏损退出，平均只剩 1.04 家，厂商分成 0.68；预算集中在一家，能力反而最高（10.9），投资者累计收益 300，劳动者只有 6.5。(c) **公共出资的两种制度**：厂商不会退出，技术轨迹与固定定价完全相同，定价只改变分配 |
| 临界值 | 私人开源能否持续取决于 $\tau_{\min}$：0.05 和 0.10 时崩溃，0.15 时平均存活 3.1 家（崩溃概率 3.7%），0.20 及以上无一退出。粗略地说，需要 $\tau_{\min}\cdot S_t\ge R$，也就是厂商靠非技术差异化获得的收入要能覆盖研发成本 |
| 意外现象 | 即使私人开源崩溃、技术停滞，25 期内劳动者和其他人的累计收益（21.9、52.2）仍高于按领先定价的私人闭源（6.5、23.8），因为公开技术免费、没有厂商分成。$\tau_{\max}$ 在 0.4–0.9 之间时排序不变（$\tau_{\max}=0.4$ 时私人闭源下劳动者为 15.6） |
| 证据 | `results/pricing/table.md` 第 B 部分及两组敏感性分析；`figure_dynamics.png` |
| 敏感性 | (1) **时间长度**：$\tau_{\max}=0.4$ 时，到第 25 期两者每期给用户的收益已几乎相等，私人闭源的技术还在增长，期数更长时排序很可能反转。(2) 假设自行使用公开技术没有成本，高估了崩溃后的价值。(3) 没有新厂商进入，也没有"降低投入以求生存"的选项，崩溃只能以退出的方式发生。(4) $K_0$ 和预算平分规则未做敏感性分析 |
| 状态 | 模拟观察 |

**含义**：这是本项目中第一次由机制推出（而不是直接假设）"开源导致私人融资不足"。它成立的条件是开源压低定价能力，且非技术差异化带来的收入不足以覆盖研发成本。同样的制度在公共出资下不会崩溃。

## F9. 厂商自己决定投入时，私人开源严重投资不足，即使定价固定也是如此

| 项目 | 内容 |
|---|---|
| 问题 | 让私人厂商自己决定投入多少（model.md §13），F8 的"开源不可持续"还成立吗？原因是定价能力下降，还是别的机制？ |
| 假设 | 多期模型；私人出资的厂商按"L × 预期收入 − 投入"选择投入，部分调整 λ=0.5，受现金约束；公共制度执行固定预算 0.3/期作对照；1,000 次抽样，25 期；主结果 L=5 |
| 结论 | (a) **私人开源几乎不投入**：固定定价下 25 期累计投入 0.71，私人闭源为 4.98，公共预算为 7.5；按领先定价时，只有前几期在惯性下投入（累计 0.30），之后为 0。技术分别停在 2.8 和 1.0。(b) **固定定价下也严重投资不足**，所以主要机制是**搭便车**：开源时，自己投入带来的进步被所有厂商免费共享，自己的市场份额不变，只能拿到进步价值的一小部分。定价能力下降（F7、F8）会进一步加剧。(c) **私人闭源前期集中投入、后期减少**：前 5 期每期 0.51–0.57，高于公共预算 0.3；最后 5 期降到 0.05–0.08。领先地位确立后，再投入的回报下降 |
| 分配 | 按领先定价时，私人闭源的累计净价值最高（46.3，公共开源为 41.6），但劳动者只得到 4.9（公共开源 26.2）。私人开源虽然技术停滞，劳动者仍得到 11.1，因为没有厂商分成 |
| 敏感性 | (1) **回报视野 L**：L 从 1 到 10，按领先定价时私人开源的投入始终为 0；固定定价时累计投入从 0.30 增到 1.45，始终远低于私人闭源（1.5–8.3）。私人闭源对 L 很敏感：L=10 时累计投入 10.8，超过公共预算。(2) **融资约束**：去掉现金约束时，私人闭源前两期出现抢份额的"军备竞赛"，投入顶到档位上限；固定定价下约 26% 的历史中所有厂商亏损退出，闭源知识随之丢失。现金约束下这种情况不再出现，且档位上限从 0.6 提到 1.0 对结果几乎没有影响。(3) **部分调整**：λ=1 时私人开源的投入呈"一期投、一期不投"的同步振荡，平均水平相近 |
| 证据 | `results/investment/table.md`、`figure.png`；投资选择的向量化计算由逐个循环的朴素计算核对（`tests/test_dynamics.py`） |
| 局限 | 近视的适应性规则，不是均衡；L 是简化形式的参数；公共预算 0.3 是外生给定的，没有优化，所以"私人闭源净价值高于公共开源"不能解读为私人制度更有效率 |
| 状态 | 模拟观察 |

**含义**：把 F8 中"开源不可持续"的原因进一步拆开：在这个模型里，私人开源的核心问题是公共品式的搭便车，定价能力下降是第二层。这直接支持"开放成果需要有人承担研发成本"：公共预算、联合出资，或让开源厂商保留某种非技术收入（F8 中的 $\tau_{\min}$ 临界值）。

## F10. "开源后技术总是到 10"来自无摩擦外溢；放松后开源优势大幅缩小，但公共出资下很少反转

| 项目 | 内容 |
|---|---|
| 问题 | 多期模型里，只要开源且厂商存活，第 25 期的能力都约为 10，与所有制、定价无关。这是结论，还是假设的产物？ |
| 假设 | 多期模型（model.md §11、§14）；每期预算 0.3 平分；η=0；2,000 次抽样，25 期，共同随机数。三个摩擦参数逐个放松，再同时放松（$\psi=0.5$，$\rho_{\text{open}}=0.6$，$\phi=0.5$） |
| 机制 | 无摩擦时，前沿每期上升 $f(R/M)\,\mathbb E[\max_j Z_j]=0.211\times1.85$，相当于四家合成一个实验室、每期取四次抽样中最好的一个，没有吸收成本，也没有路线趋同。这是开源优势的上限 |
| 结论 | (a) **公共出资下，开源优势随三种摩擦都缩小，但很少反转**。第 25 期公共开源比公共闭源多用上的能力：无摩擦时 +3.53；$\psi=0.5$ 时 +1.88；$\psi=0$ 时 +0.09（仍为正，因为用户当期仍能用上 $H$）；$\rho_{\text{open}}=0.6$ 时 +1.93；$\phi=0.5$ 时 +1.60（相对优势从 55% 降到 42%）；三者同时放松时 +0.50（13%）。只有当开源厂商的研究几乎完全同质（$\rho_{\text{open}}\gtrsim0.93$，看累计净价值；看能力约为 0.95）时，开源才不如闭源。(b) **私人出资、固定定价时，反转来得早得多**：私人开源的能力在 $\psi\lesssim0.47$ 或 $\rho_{\text{open}}\gtrsim0.63$ 时低于私人闭源，累计净价值在 $\psi\lesssim0.2$ 或 $\rho_{\text{open}}\gtrsim0.77$ 时低于私人闭源。原因是私人闭源中落后厂商退出，预算集中到存活者手中；在 $\alpha=0.6$ 下，集中投入比"四家各投 1/4、取最好的一家"更有效。三种摩擦同时存在时，两者能力几乎相同（4.33 对 4.36），开源的累计净价值略高（27.8 对 27.0）。(c) **按领先定价时**，私人开源在所有摩擦设定下都崩溃（F8），摩擦使崩溃后公开技术的水平更低（无摩擦时 3.8，三者同时放松时 1.8） |
| 分配 | 按领先定价、三种摩擦同时存在时，**公共开源下劳动者的累计收益低于公共闭源**（17.5 对 18.6），无摩擦时则相反（26.4 对 24.3）。开源把厂商分成压到 $\tau_{\min}$，价值从厂商所有者转到应用端；在广泛所有权下，劳动者拥有 60% 的厂商，却只得到 40% 的应用端收益。摩擦使开源带来的技术增量不足以弥补这部分损失。投资者和其他人仍从开源中获益 |
| 证据 | `results/spillovers/table.md`（含 $\rho_{\text{open}}$ 细扫描，差值为同一历史成对比较，±2 SE）、`figure.png`；三个参数的实现由 `tests/test_frictions.py` 检查（默认值逐位复现旧结果；$\psi=0$ 时公开前沿等于闭源路径的累计最大值；$\rho_{\text{open}}$ 校准） |
| 局限 | 摩擦参数没有经验校准，取值是示意性的；$\psi$ 不随自身研发投入变化；闭源厂商的冲击相关性不随制度变化；私人闭源的优势依赖"预算平分给存活者"和 $\alpha<1$，未做敏感性分析；只用了政策预算，没有结合内生投资（F9） |
| 状态 | 模拟观察 |

**含义**：动画和 F6–F9 中的开源结果应理解为开源优势的**上限**。"开源比闭源好多少"主要取决于开源成果能否被吸收、是否导致研究路线趋同，模型本身无法回答这两点，需要经验证据。较稳健的结论是：在公共出资下，开源的技术优势在很宽的摩擦范围内仍为正，但它对劳动者的分配效果可能为负。私人出资下，"开源 vs 闭源"的比较则对这些摩擦以及预算集中规则都很敏感。

## F11. 公共实验室一般不挤出私人**闭源**厂商的研发，开源的公共实验室反而让它们多投入；但私人厂商本身开源时，开源的公共实验室会完全挤出私人研发

| 项目 | 内容 |
|---|---|
| 问题 | 公共出资（尤其是公共开源）会不会削弱私人厂商研发的积极性（挤出效应）？公共实验室自己效率低又会怎样？ |
| 假设 | 混合制度（model.md §15）：3 家私人闭源厂商按 §13 自主投入（$L=5$，受现金约束），加一家公共实验室（每期预算 0.15，税收出资，全民所有，不退出），分为不存在、闭源、开源三种情况；1,000 次抽样，25 期，共同随机数；差值为同一历史成对比较，给出 ±2 SE |
| 结论 | (a) **开源的公共实验室挤入私人研发**：25 期私人累计投入从 5.18 增到 7.79（+2.61 ± 0.11，领先定价），固定定价下 +3.28 ± 0.21。在 $L=2,5,10$、两种定价、预算 0.075–0.3、三种摩擦同时存在时，方向都不变。(b) **机制是"保持竞争激烈"**：没有公共实验室时，一家私人厂商很快领先，其他厂商基本停止投入（最后 5 期私人每期只投 0.08）。开源实验室不断抬高所有厂商都能用的公共基础，把落后者拉回来，领先者对第二名的优势从 8.1 缩小到 4.0，大家必须继续投入才能保持领先。开源实验室自己几乎没有市场份额（约 1%），实际上成了私人厂商的"上游供应商"。时间上也有差别：领先定价下第 3–7 期，有公共实验室时私人投入略低（约 0.31 对 0.38），也就是前期有短暂的挤出；之后没有实验室的情况下私人投入很快萎缩，累计结果是挤入。(c) **闭源的公共实验室，挤入或挤出取决于私人厂商看多远**：$L=2,5$ 时为挤入（+1.54、+0.86），$L=10$ 时为**挤出**（领先定价 −1.37 ± 0.32，固定定价 −0.30 ± 0.13），技术几乎没有提高。看得远的私人厂商指望赢家通吃、长期收租，一个不会退出的公共竞争者削弱了这个前景。(d) **公共实验室效率低（$e$ 小）不会让私人更不投入，只是浪费钱**：$e$ 从 1 降到 0.25 时，挤入和技术增量都逐渐消失；$e=0.25$ 时技术与没有实验室几乎相同，累计净价值少 3.85，约等于全部公共支出 3.75。(e) **私人厂商本身开源时，结论不同**：固定定价下，开源的公共实验室把私人投入从 0.79 压到 0.23（每期纳什规则下几乎为 0），是**完全挤出**。私人开源厂商的成果本来就不能形成差异，开源实验室又给了大家相同的起点，自己投入就没有回报。闭源的公共实验室则相反，私人投入从 0.79 增到 2.47，因为它是需要超过的竞争者。领先定价下，私人开源厂商无论有没有实验室都几乎不投入（F9），无可挤出，但实验室把技术从 0.9 提高到 8.3，几乎全部由公共实验室提供。(f) **对投资规则稳健**：把适应性规则换成每期纳什均衡（§13 第 4 条，8 轮后基本收敛，步长超过半个档位的比例不超过 0.2%），私人闭源厂商的结论几乎不变：开源实验室下 +2.84（领先定价）、+3.50（固定定价），闭源实验室下 +1.11、+1.42 |
| 净价值 | 在这组参数下，公共实验室几乎总是**降低** 25 期累计净价值（−0.7 到 −5.5），只有 $L=2$ 时持平或提高：领先定价下约 +1.9；固定定价、闭源实验室下 +0.36 ± 0.29，不显著。技术提高了（开源实验室 +3.1），但多出的研发很多是私人厂商之间的重复竞赛，再加上价值函数是凹的（$\gamma=0.5$），这些研发的社会回报低于成本。这个结论依赖 25 期截断（第 25 期后的技术价值没有计入）和 $\gamma$ |
| 分配 | **开源的公共实验室把收益转给私人所有者**：与闭源公共实验室相比，投资者累计收益更高（领先定价 296 对 264），劳动者更低（8.9 对 14.2）。闭源实验室能占到 28% 的市场份额，利润归全民；开源实验室的成果则被私人厂商拿去，在此基础上收费。实验室预算越大，这个差别越明显：劳动者收益的差距从预算 0.075 时的 1.7 增到 0.3 时的 11.6（领先定价）|
| 证据 | `results/mixed/table.md`（预算、效率、回报视野 L、摩擦四组敏感性，以及私人开源 × 两种投资规则）、`figure.png`；混合出资、不存在的厂商、效率由 `tests/test_mixed.py` 检查；原有设定下与修改前的代码逐位一致 |
| 局限 | (1) 每期纳什规则检验了"对手不变"的预期假设，但收益仍是简化形式的 $L\cdot\mathbb E[\tau v]$，会计入抢来的份额，所以"竞赛式挤入"可能仍被放大；完整的动态均衡可能不同。(2) 效率 $e$ 是外生的，没有从公共实验室的激励结构推出来；公共预算也是外生的，没有优化，也不随表现调整。(3) 私人厂商要么全部闭源，要么全部开源，没有混合；私人厂商也不能对公共实验室的出现作出改变开源策略的反应。(4) 没有新厂商进入 |
| 状态 | 模拟观察 |

**含义**："公共支持开源会不会削弱私人研发积极性"，取决于私人厂商自己是否开源。私人厂商闭源时，一般不会削弱，反而相反：公开的公共基础让竞争保持激烈，私人投入增加；挤出只出现在公共实验室闭源、私人厂商着眼长期垄断收益时。私人厂商开源时，开源的公共实验室会完全取代私人研发，这时技术进步几乎全靠公共预算，公共预算的规模就成了关键。真正需要关注的问题是另外两个：(1) 多出来的私人研发很大程度上是重复竞赛，净价值不一定提高；(2) 开源公共实验室的成果主要被私人所有者变现，劳动者的收益反而不如闭源公共实验室。如果目标是分配，那么公共成果开放之后，还需要配套的收益分享或定价约束。
